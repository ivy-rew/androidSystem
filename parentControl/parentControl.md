# Parent Control

Save mobile device usage for the family.

## FamilyLink

Pro
- parent mgmt app requires no installation; runs in the web https://familylink.google.com
- Seems to enforce YouTube app: filters explicit content from child eyes
- Sends mails for every app installation on the child device

Con
- Can only be enforce until the child is 13; opt-in possibility remains
- Hard time limits per app: no group of similar tools with same ruleset
- Seems to enforce Google's YouTube app -> shows ads

Block
- apps are greyed out: if started anyway transparently informs on the reached limit
- Limits permission like "location" to only be managed by the parent. This default can be changed per permission on the familylink mgmt interface.
  

## TimeLimit.io

https://timelimit.io/en/

Pro
- Clustering of similar apps (apply one group rule-set for all of them)
- Very advanced rules: time per da, special days, extra time, ...

Con
- Bypassable (only an app overdraw)
- Complex setup
- Requires a lot of white-listing; app grouping (or relaxed defaults)

Ok
- For 1 Euro per month, child device policies can be changed from parent device

Block
- app overlay displaying rule and category hit transparently

Troubleshooting
- device must be assigned to the "child": or no limits will ever apply

## Learned

- Browsers remain hard to control
  - FamilyLink can only control contents in Chrome
  - Game play in Browser is not recorded as game-play in both apps
- Digital well-being apps help the kids to control habits
  - track browser usage: https://addons.mozilla.org/en-US/firefox/addon/webtime-tracker-2/
  - usage tracker without enforcing any rules: https://f-droid.org/en/packages/godau.fynn.usagedirect/
